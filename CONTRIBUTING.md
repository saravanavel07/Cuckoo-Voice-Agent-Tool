# Contributing to CUCKOO VOICE AI

We welcome contributions to Cuckoo Voice AI!

## Code Guidelines
- Follow TypeScript conventions with strict typing.
- Use Tailwind CSS with our organic forest-and-leaf palette (`#65E62E`, `#8AFF42`, `#159447`, `#082D19`, `#F4FFF1`, `#123D25`).
- Ensure accessible design with keyboard shortcuts and reduced-motion considerations.
- Run `npm run lint` and `npm test` before submitting changes.

## Development Setup
1. Clone the repo: `git clone https://github.com/your-org/cuckoo-voice-ai.git`
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. Open `http://localhost:3000` in Chrome or Edge with microphone enabled.
